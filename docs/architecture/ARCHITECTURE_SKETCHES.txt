7. WASTE DETECTION PATTERNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pattern 1: MODEL MISMATCH
┌─────────────────────────────────────────┐
│ Simple Task + Expensive Model = WASTE   │
│                                         │
│ Task: "Classify sentiment: positive?"   │
│ Model Used: GPT-4 ($$$)                 │
│ Recommended: GPT-3.5-Turbo ($)          │
│ Savings: 95%                            │
└─────────────────────────────────────────┘

Pattern 2: DUPLICATE REQUESTS
┌─────────────────────────────────────────┐
│ Same Prompt Hash = DUPLICATE            │
│                                         │
│ Prompt: "Summarize quarterly report"    │
│ Occurrences: 47 times in 1 hour        │
│ Recommendation: Implement caching       │
│ Savings: 98%                            │
└─────────────────────────────────────────┘

Pattern 3: UNUSED OUTPUT
┌─────────────────────────────────────────┐
│ Large Completion + No Usage = WASTE     │
│                                         │
│ Requested: 2000 tokens                  │
│ Actually Used: 150 tokens               │
│ Wasted: 1850 tokens (92.5%)            │
│ Recommendation: Reduce max_tokens       │
└─────────────────────────────────────────┘
